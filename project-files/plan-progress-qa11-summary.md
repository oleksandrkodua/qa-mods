# plan-progress 0.7.6-qa.11 — что сделано (для другого чата)

Дата: 07.10.2026. Рабочая копия: `~/Desktop/MODS/plan-progress/` (с 08.10.2026 единственная; раньше была `~/Desktop/СLAUDE files /mods/plan-progress/` и попадала в `MODS` через rsync).

## Зачем
Живая проверка полос показала три проблемы:
1. В полосе вместо названия этапа стоял бейдж с цифрой.
2. Завершённые (done) полосы пропадали: ни зелёной на 100%, ни свёртки `✓ N готово ▾`.
3. Под полосой нельзя было посмотреть шаги.

## Причины (найдены в `hooks/register.tsx`)
- Цифра вместо названия: `NARROW = 360`. Если дорожка уже 360, бейдж рисуется кружком с номером этапа. Длинный заголовок сужает дорожку.
- Пропажа done: `placeBar` при больше чем `MAX_BARS = 5` полос выкидывал завершённые первыми. Поэтому при 7 полосах «q1», «q2» исчезали («no bar»).
- `▾` под полосой показывался только для обрезанного заголовка и раскрывал только заголовок.
